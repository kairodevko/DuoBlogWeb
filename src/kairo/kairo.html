Projects

He trabajado en varios proyectos personales y colaborativos. Aquí tienes algunos de ellos:

  • Sistema de Inventario de Ferretería: Desarrollé un sistema de inventario para una ferretería local utilizando Python y Excel.
    El sistema permite a los empleados gestionar el inventario, realizar seguimiento de las ventas y generar informes.
    Cada reporte se guarda en un archivo de excel con el formato "Reporte_YYYY-MM-DD.xlsx", donde se registran las ventas diarias, el inventario actualizado y las ganancias obtenidas.
  • Mini Juego de cafetería: Desarrollé un pequeño juego interactivo utilizando HTML, CSS y JavaScript.
    El juego simula que prepares tu propio café con diferentes ingredientes y opciones de personalización.
    El objetivo es crear la bebida perfecta para tus clientes virtuales y ganar puntos por cada pedido exitoso.
